# Plataforma de Aprendizaje en Línea - Culinary Arts School

Proyecto de titulación orientado al desarrollo de una plataforma de aprendizaje en línea para cursos cortos asincrónicos.

## Stack tecnológico

- Frontend: React, Tailwind CSS, React Router, Axios
- Backend: FastAPI, SQLAlchemy, Alembic, JWT, bcrypt
- Base de datos: PostgreSQL
- Despliegue: Docker, Docker Compose, Dokploy
